# Automated-Network-Request-Management
ServiceNow-based solution for automating network request submission, approval, fulfilment, and tracking.

Platform
. ServiceNow

Project Type
. ITSM
. Incident Management

1. Project Objectives
Automate Network Requests
Automate the complete lifecycle of network-related service requests from submission to closure.
Reduce Manual Effort
Minimize manual data entry, request tracking, approval handling, and communication.
Improve Request Processing
Provide a structured workflow for faster and more consistent request processing.
Automate Approvals
Automatically route requests to the appropriate approver based on the configured workflow.
Centralized Request Management
Store network request information in ServiceNow tables for easy access and tracking.

2. Technologies / ServiceNow Features Used
Technology / Feature	Purpose in Project
ServiceNow Platform	Main platform used to develop the project
Service Catalog	Allows users to submit Network Requests
Service Portal	Provides the user-facing interface for submitting requests
Custom Table	Stores network-related request information
Custom Fields	Captures requester and network request details
Flow Designer	Automates the request workflow
